# 测试标准

## L1–L4

- L1：验证单点入口、输入、响应和基本状态；
- L2：验证核心业务流程和最终状态；
- L3：验证分支、异常、超时、重试、幂等、副作用和清理；
- L4：验证结果、路径、代码、数据、Trace、覆盖率、Commit 和发布准入。

## 统一要求

- 每次运行必须有唯一 `run_id`；
- 真实业务事件必须在真实执行位置产生；
- 状态必须区分 `passed`、`failed`、`not_observed`、`not_applicable`；
- 固定延时、HTTP 200 或 UI 动画不能作为成功证据；
- 测试报告必须能追溯到剧本、环境、版本和 Commit；
- 未观察到证据时不得声明通过。
