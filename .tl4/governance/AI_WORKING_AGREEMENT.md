# AI 工作协议

## 基本原则

AI、Codex、WorkBuddy 是项目协作者，不是项目最终责任人。它们必须先读取项目规则、任务和相关设计，再修改代码。

## 修改前

1. 说明目标、影响范围和预计修改文件；
2. 检查当前 Git 状态，不覆盖已有用户修改；
3. 搜索现有实现、测试和文档，避免重复建设；
4. 对删除、移动、外部发布、真实副作用和凭据操作先请求确认。

## 执行中

- 可继续的工作继续执行，不因单个非阻塞问题停住；
- 阻塞问题记录到任务板和问题清单；
- 不把推测写成已验证事实；
- 不把演示 fixture、mock 或固定动画当作真实测试证据。

## 完成时

- 运行与风险相称的检查；
- 报告已完成、未完成、阻塞和未验证事项；
- 同步设计、映射、测试和变更记录；
- 不声称未实际验证的服务、路由或部署已经可用。
