## 启动

```bash
python3 -m http.server 4173 --directory .
```

浏览器访问 `http://localhost:4173/`

## 一句话总结

**4 角色 + 双入口 + 角色工作台 + AI Copilot + 预算编制/追踪/决算全闭环**，让客户从熟悉的角色操作习惯平滑过渡到 AI 辅助。

## 4 角色权限矩阵

| 角色 | 可见页面 | 数据范围 | 典型任务 |
|---|---|---|---|
| **总经理** | 预算总览 / 明细 / 审批 / 决策 / 编制 / 追踪 / 决算 | 全局 | 全局决策 · 终审 · 决算 |
| **财务管理员** | 同总经理 | 全局 | 预算汇总 · 调整 · 决算 |
| **部门经理** | 预算总览（本部门） / 明细 / 审批 / 编制 / 追踪 | 本部门 | 编制本部门 · 部门审批 · 偏差追踪 |
| **员工** | 工作台首页 / 明细 / 审批中心 | 本人发起 | 发起采购/报销 · 查看单据进度 |

## 双入口

顶栏左侧「**工作台** \| **AI Copilot**」并列：

- **工作台**：按角色渲染子导航 + 内容。日常事务、表格化操作（传统软件熟悉的路径）。
- **AI Copilot**：对话式智能助手 + 四类卡片（预测/分析/建议/执行）+ 证据链。AI 主动发现问题。

## 演示路径（推荐顺序）

1. **登录页**：4 张角色卡，点击进入或右上角"切换角色"
2. **角色工作台**：按角色看不同首页（待办 + 快捷功能 + AI 关注）
3. **预算编制**（总经理）：自上而下分解 + AI 按历史占比预填
4. **预算追踪**（部门经理）：月度执行表 + AI 偏差归因
5. **决算**（总经理）：全年实际 vs 预算 + AI 处理建议
6. **AI Copilot**（员工/任意角色）：问"哪个部门会超预算？"、"采购显示器"等

### URL deep-link（演示/截图用）

- `?as=adminHead&dept=admin` — 公司行政负责人（行政部）
- `?as=expense` — 基层费用责任岗（IT 部张伟）

## 预算编制双模式

| 模式 | 流程 | 角色 |
|---|---|---|
| **自上而下分解** | 总经理定年度总额 → AI 按历史占比分配到部门 → 提交 | 总经理 / 财务 |
| **自下而上填报** | 部门经理填报本部门各科目 → 财务汇总 → 总经理批 | 经理填报 / 财务汇总 / 总经理批 |

**AI 编制助手**：按 1-9 月历史执行年化 + 8% 缓冲，生成建议额度，经理可调整。

## 状态机（编制流程）

```text
编制中(draft) → 部门填报(submitted) → 公司预算管理员汇总(finance_approved) → 集团 CEO 审批(approved)
                    ↓
                退回修改(rejected) ← 总经理驳回
```
