## 阶段 1 · MVP（目标一：预算编制及统计自动化）`P0`

**目标**：典型法人公司一次填报 → 多口径自动生成 → 碰撞 → 协商留痕。

| # | 任务 | 对应模块 | 交付物 | 验证 |
|---|---|---|---|---|
| 1.1 | 组织与权限底座（角色、数据范围、敏感密级骨架） | M1 | 用户/角色/数据范围 API | 不同角色仅见授权范围数据 |
| 1.2 | 预算编制任务与一次填报（9 种方式 + 月度分解） | M3 | 编制工作台 | 基层按经济事项填一次，生成五维明细 |
| 1.3 | 规则引擎预填与偏离校验 | M6 | 规则评估服务 | 办公费类默认降5%预填；偏离须填原因 |
| 1.4 | 多口径自动生成（财务/管理/事业部/管理层视图） | M2/M3 | 映射聚合服务 | 同一填报自动出多口径，与手工口径一致 |
| 1.5 | 预算版本与平衡引擎（版本头+明细+变更+快照） | M4 | 版本服务 | 五维任一层级汇总一致；批准版不可变 |
| 1.6 | 碰撞与协商闭环（状态机 + 留痕） | M5/M10 | 争议工作台 | 申报 vs 建议差异展示；协商状态机流转并留痕 |
| 1.7 | 审计与证据链埋点 | M10 | 审计服务 | 任意金额变更可追操作人/时间/原因/证据 |
| 1.8 | Copilot 基类（约束对象结构 + 自然语言草稿，局部） | M11 | Copilot 入口 | 自然语言要求→待确认约束→可编辑草稿 |

**阶段 1 出口验证**：选定 1 家典型法人公司，走通 填报→规则预填→多口径汇总→碰撞→协商确认→批准版，金额与汇总经确定性测试一致。

**目标**：费控 Excel 单向导入 → 预算 vs 实际 → 超标预警。

| # | 任务 | 对应模块 | 交付物 | 验证 |
|---|---|---|---|---|
| 2.1 | 费控 Excel 导入适配器（模板+映射+重复检测） | M8/集成层 | 导入服务 | 样例 Excel 导入后按五维+月度归集，重复导入被检测 |
| 2.2 | 预算 vs 实际对比与执行率 | M8/M4 | 执行数据模型 | 执行率 = 累计实际/预算，跨口径对齐 |

**阶段 2 出口验证**：导入样例费控数据，执行看板展示执行率/超标，与预算口径匹配无错位。

## 阶段 3 · AI 风险筛查（目标三：提示非判定） `P2`

**目标**：从海量数据中「拎出」高风险对象，人工复核。

| # | 任务 | 对应模块 | 交付物 | 验证 |
|---|---|---|---|---|
| 3.1 | 指标层（历史/实际/同比/单位成本/执行率） | DWH | 指标服务 | 指标可被查询且口径统一 |
| 3.2 | 规则初筛（错科目/费用转移/异常金额频率/结构异常/单位差异） | M7 | 初筛规则 | 预设样例可识别已知错科目/转移 |
| 3.3 | LLM 解释与候选方案层（不输出最终金额） | M7/AI | 诊断编排 | 输出结构化诊断，金额由确定性计算给 |
| 3.4 | 风险筛查 → 人工复核闭环 | M7/M10 | 风险工作台 | 风险提示→人工采纳/驳回→审计留痕 |
| 3.5 | 成熟度分组对标（老厂千分级 vs 新模块百分比级） | M5/M7 | 对标视图 | 分组基线正确，不跨组一刀切 |

**阶段 3 出口验证**：用样例报销数据跑通风险筛查，高危项被提示且可追溯到数据/规则，人工复核结论回流审计。

## 跨阶段约束

1. **确定性优先**：金额/汇总/执行率/压降目标一律确定性计算，AI 不输出最终金额（D3）。
2. **测试伴随**：每阶段配套回归测试，重点校验五维汇总一致、版本不可变、协商留痕完整。
3. **不碰边界**：八项不做（改造费控/替代报销/事前锁预算/实时费控/AI 审批/AI 判定/AI 定压降/集团财务平台）一期不开发。
4. **待确认阻塞**：M1/M2 权限与归口依赖 V2 §8 待确认项（11 中心全清单、口径映射、事业部归属、敏感密级）闭环后方可定稿，否则先以样例假设并在文档标注。
