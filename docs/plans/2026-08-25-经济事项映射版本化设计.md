# 设计文档｜经济事项映射纳入版本化（与 baseline/flow 同生命周期）

> 状态：✅ 已定稿并落地（2026-08-25）
> 关联：`2026-08-25-预算规则三Tab重构设计.md`（Tab3 已落库 per-version）、`2026-08-25-预算规则分组归类设计.md`
> 门禁：讨论 → 设计 → 开发。松哥 2026-08-25 在选项中拍板「克隆继承 + 草案可编辑」。

## 一、问题（为什么"也"要版本化）

数据模型 `rule_item_event` 已带 `version_id`（`server/db.js:1049`），`getEventMap/putEventMap` 均按版本读写，Tab3 编辑也是存到"当前生效版本"——**关联的版本化其实做了一半**。但存在一个真实缺口：

- 后端 `createRuleVersion`（`server/db.js:1126`）克隆 `budget_rule_item`（baseline + flow）时**没有克隆 `rule_item_event`**。
- 因此 Tab4「生成草案版本」产生的新版本 event-map 是**空的**；发布后 Tab3 显示为空白勾选——即"经济事项映射没跟着版本走"。
- 另有静态双轨残留：`renderScopeExplain`（`website/views/rules.js:200`）仍读前端写死的 `BM.RULE_EVENT_MAP`（仅用于规则卡"政策表述/说明"弹层文本，不影响关联），后端版本化 map 未接管该展示。

松哥原话："预算规则中的经济事项映射其实也设计版本，请一并处理"。

## 二、拍板方案（松哥选 A）

**克隆继承 + 草案可编辑**：

1. **克隆继承**：Tab4 生成草案时把当前生效版本的 event-map 一并克隆进草案（后端 `createRuleVersion` 加 `cloneEventMap`），生成即带完整映射，与 baseline/flow 一致。
2. **草案可编辑**：Tab3 编辑器从"写死 active"升级为"可对任意版本（含待发布草案）编辑"——顶部加版本切换器，发布即整体切换。
3. 发布 / 恢复历史版本均不另做克隆：草案在被创建时已带映射、可在 Tab3 单独改；发布仅翻转 `status`，映射始终跟随版本 id。

## 三、改动清单（P1–P4）

| 阶段 | 文件 | 改动 |
|---|---|---|
| P1 后端 | `server/db.js` | 新增 `cloneEventMap(db, fromId, toId)`；`cloneRuleVersion` 克隆 items 后调用（active→草案） |
| P2 前端 | `website/views/rules.js` | `renderEventsTab` 加 `.evt-ver-sel` 版本切换器（默认 active，可切草案/历史）；`target` 取代 `active` 驱动标题/规则卡/加载/保存；`saveEventMap` 按 `target.id` 写 |
| P3 CSS | `website/styles/components.css` | `.evt-ver-bar` / `.evt-ver-sel` 样式 |
| P4 E2E | `tests/e2e/create_next_rule.e2e.cjs` | 生成草案后断言 `draft.event-map` 关联集合 == active.event-map（克隆继承） |
| P4 E2E | `tests/e2e/rules_event_map.e2e.cjs` | 改硬编码 versionId=1 为动态 activeId；新增版本切换器断言（存在 + 切换加载对应版本映射） |

## 四、不做的范围（明确划界）

- **静态 `BM.RULE_EVENT_MAP` 双轨清理**：仅用于 Tab1 规则卡"政策表述/说明"弹层文本展示，不影响关联本身；后端 `rule_item_event` 只存 `subjectIds` 不含 policy/desc 文本，完全去静态需把政策文本也落库，超出本任务。本轮保留，后续另议。
- 移动端 `budget.js` 按既定范围暂不接 event-map 版本切换。
- 历史版本映射的"回滚/对比"可视化不在此轮。

## 五、验证

- `node --check` 全绿；`cloneEventMap` 随 `createRuleVersion` 事务内执行。
- E2E：`create_next_rule` 断言草案 event-map == active（克隆继承）；`rules_event_map` 断言版本切换器 + 动态 active 持久化。
