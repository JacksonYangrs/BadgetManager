## 1. 目标边界

- **A 路径（必做）**：看板所有金额取自 `unit_budget` 真实数据，按组织树聚合到当前下钻节点；执行 = 当期累计（真实上年实际 × 月度占比推算，确定性）。
- **B 路径（必做）**：新增 `budget_execution` 逐月执行表 + 接口 + 种子（根于 `last_year`），看板执行优先取真实逐月；无逐月时回退 A 推算。接口设计成**可直接替换为财务系统 Excel 导入**。
- **角色×数据范围（补完原设计缺口）**：事业部经理/管理中心只看自己 org 子树聚合，不再全角色一致（原 demo 局限消除）。
- **不新增**：不碰预算计算逻辑、不新增经济事项字段。

## 2. 数据模型

### 2.1 新增表 `budget_execution`（B 路径）
```sql
CREATE TABLE IF NOT EXISTS budget_execution (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  org_id INTEGER NOT NULL,
  cat TEXT NOT NULL,
  month INTEGER NOT NULL CHECK(month BETWEEN 1 AND 12),
  amount INTEGER NOT NULL DEFAULT 0,
  UNIQUE(org_id, cat, month)
);
```
- 种子生成（幂等）：对 `unit_budget` 每行，取 `last_year`（真实上年实际）按该 cat 的 `monthly` 占比摊到 12 月写入（`budget_execution`）。
  - 公式：`exec[m] = round(last_year * monthly[m] / sum(monthly))`。
  - 若 `monthly` 全 0 或空，均摊 12 月。
  - **标注**：这是"基于上年实际×月度分布的推算执行"，非财务系统回传真实支出；接口/UI 明确区分。
- 预留真实导入：`PUT /api/executions` 支持按 (org_id, cat, month) upsert，财务 Excel 导出后直接灌入替换种子。

### 2.2 复用表
- `unit_budget`：`amount`(本年预算) / `monthly`(本年 12 月预算分布) / `last_year`(上年实际年值)。
- `organization`：org 树聚合。

## 3. 执行口径定义（统一函数，A/B 共用）

```
当期切片(period):
  months = periodMonths(period)        // 年=[1..12] 季=[q*3-2..q*3] 月=[m]
  预算累计 = Σ monthly[m] for m in months
  执行累计 = Σ exec[m]   for m in months   // exec 来自 budget_execution（B），无则 last_year×占比推算（A）
  偏差     = 执行累计 − 预算累计
  偏差率   = 偏差 / 预算累计 × 100%
  预警     = |偏差率| ≥ 10% ? (偏差率>0?"danger超支":"warn临界") : "ok"
  执行率   = 执行累计 / 预算累计 × 100%
```
