## 3. 关键场景与断言口径（总览）

1. **4 级树结构正确**：`parent_id`/`level`/`path` 三者自洽（子 level = 父 level+1；path = 父 path + 自身 id 段）；层级 ∈ {1,2,3,4}；DFS 无环、无重复到达路径。
2. **叶子经济事项挂载**：所有 `economic_event.subject_id` 指向 level=4 叶子；level<4 节点不得被引用；旧 6 个 seed 事件不悬空。
3. **增删改 + 双拦截**：删除有子节点 → 400；删除被引用叶子 → 400；改 parentId 防环 → 400；合法叶子删除 → 200。
4. **级联表单**：挂载层级下拉只列「可挂载层」（叶子）；选分类节点不可挂经济事项。
5. **向后兼容**：`/api/subjects`、`/api/events` 平铺响应字段不破坏；`rowToSubject` 旧调用方仍可用；树接口独立提供。
6. **数据幂等**：seed 重复执行不重复插入（节点数/经济事项数不增长）。
7. **数据完整性**：Excel 353 + 145 条不重不漏映射到树/叶子，与 manifest 对账一致。
