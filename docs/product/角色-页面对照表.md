## 1. 角色清单（9 个）

| 角色 code | 名称 | 层级 scope | 职责定位 |
|---|---|---|---|
| `admin` | 系统管理员 | all（平台） | 账户 / 组织 / 角色管理 · 平台运维 · 基础数据 / AI 配置维护 |
| `ceo` | 集团 CEO | group（集团） | 集团总额 · 压降目标 · 重大争议决策 · 终审 |
| `cooLead` | 总经办负责人 | group（集团） | 组织审核 · 牵头协商 · 推动压降下达 |
| `cooAnalyst` | 总经办预算管理员 | group（集团） | 汇总 · 规则引擎 · 导入核对 · 执行跟踪 · 总控 |
| `legalHead` | 法人公司负责人 | company（本公司） | 审核本公司预算 · 参与协商 · 重大调整 |
| `adminHead` | 公司行政负责人 | company（本公司） | 组织编制 · 解释差异 · 落实压降 |
| `companyBudgeter` | 公司预算管理员 | company（本公司） | 汇总校验 · 规则校验 · 提交 · 费控导入 |
| `centerOwner` | 归口责任人 | center（归口科目） | 归口科目专业标准 · 跨公司查看 · 风险关注 |
| `expense` | 基层费用责任岗 | self（本人项目） | 本人负责项目 · 一次填报 · 双派生视角 |

> scope 语义：group=集团全量 / company=本公司+下属 / center=归口科目跨公司 / self=仅本人项目 / all=平台运维。

## 2. 页面清单（19 个）

| 页面 key | 导航标签 | 功能一句话 |
|---|---|---|
| `wb-home` | 工作台首页 | 角色专属工作台：待办 / AI 推送 / 任务入口 |
| `compile` | 预算编制 | 按经济事项一次填报、九法预填、月度分解、偏离说明 |
| `rules` | 预算规划 | 编制 / 追踪 / 余量 / 超预算策略（规则引擎内容） |
| `balance` | 汇总平衡 | 五维任一层级汇总一致性校验（仅集团层可见） |
| `kanban` | 预算跟踪 | 预算执行跟踪看板（含对标子面板，按角色显隐） |
| `track` | 预算追踪 | 月度执行追踪与偏差归因 |
| `final` | 决算 | 年度决算：结余 / 超支处理方案 |
| `adjust` | 预算调整 | 调剂 / 追加 / 调减 |
| `importView` | 费控导入 | 费控 Excel 导入（模板 / 映射 / 对账 / 错误修正） |
| `approval` | 审批中心 | 审批单按角色范围过滤 |
| `decisions` | 决策中心 | AI 优化建议采纳 / 回滚 |
| `collision` | 碰撞 | 申报值 vs 建议值差异与争议项 |
| `collisionTune` | 碰撞调参 | 滑块即时调参（申报额 / 压降比率），右侧实时出结果 |
| `dashboard` | 预算总览 | 预算执行与风险总览（按角色维度裁剪） |
| `benchmark` | 对标 | 横向对标（仅集团层可见，同级 / 下级不可看） |
| `riskView` | AI 风险 | AI 风险筛查：提示非判定，人工复核 |
| `basedata` | 基础数据 | 组织 / 科目 / 规则字典维护（可编辑角色限定） |
| `accounts` | 预算工作人员 | 用户账户维护（可编辑角色限定） |
| `ai-config` | AI 配置 | AI 模型 / 策略配置（限定角色） |

> 备注：`plan` / `projects` 等旧视图文案已并入 `compile` / `kanban` 或移除，不在当前导航集；`details` 已移除（v0.6）。

## 4. 各角色使用场景（一句话流程）

| 角色 | 进来首屏 | 持续做什么 | 核心流程 |
|---|---|---|---|
| 系统管理员 | 工作台（运维台） | 维护账户 / 组织 / 角色 / 基础数据 / AI 配置 | 登录 → 运维台 → 日常平台维护 |
| 集团 CEO | 集团总览 + 工作台 | 定压降目标 / 终审 / 采纳 AI 建议 / 监控风险 | 总览 → 定目标 → 终审 / 采纳 → 监控执行与风险 |

| 总经办预算管理员 | 工作台 | 汇总校验 / 规则 / 导入核对 / 执行跟踪 / 风险复核 | 汇总 → 规则校验 → 生成建议版 → 碰撞 → 风险复核 → 跟踪 |
| 法人公司负责人 | 工作台（本公司） | 审核本公司预算 / 参与协商反馈 / 重大调整 | 登录 → 审核本公司 → 协商反馈 → 重大调整 |
| 公司行政负责人 | 工作台（本公司） | 组织编制 / 解释差异 / 落实压降 | 登录 → 组织编制填报 → 解释差异 → 落实压降 |
| 公司预算管理员 | 工作台（本公司） | 汇总各部门 / 规则校验提交 / 费控导入 | 登录 → 汇总校验 → 提交 → 费控导入对账 |
| 归口责任人 | 工作台（归口） | 维护归口科目标准 / 跨公司查看 / 风险关注 | 登录 → 维护归口标准 → 跨公司查看 → 风险关注 |

## 5. 当前实现备注（优化点，待客户确认）

1. **菜单 vs 卡片入口不统一**：当前 `roleViews` 顶部菜单仅含核心 5 项（`wb-home` / `compile` / `kanban` / `rules` + 角色特定如 `balance` / `basedata` / `ai-config` / `accounts`），其余页面（如 `dashboard` / `approval` / `track` / `final` / `collisionTune` / `riskView` 等）经**工作台首页卡片 / 按钮**进入。这正是后续「按角色任务流重排页面」要统一的优化方向。
2. **调节机制（M5 即时调参）**：`collisionTune` 滑块即时反馈已落地，建议在员工压降试算、各级碰撞协商等所有「调预算 / 调参数」场景统一复用。
3. **可配置落点**：角色、scope、页面勾选、默认视图均应由配置驱动（`BM.ROLES` / `roleViews` / 后端 role 表），本表为确认基线，客户定稿后回填配置即可。
