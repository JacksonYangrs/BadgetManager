## 2. 客户规则引擎可视化（P0）

### 2.1 规则字典（来源文件1「预算逻辑」，提炼）

```js
BM.RULES = [
  { id: "R01", cat: "总办办公费", type: "down5",   expr: "较2025实际下降5%", requireReason: true },
  { id: "R02", cat: "食堂费用",   type: "canteen", expr: "人均成本7元/餐±3%，>7.5须降≥5%", requireReason: true },
  { id: "R03", cat: "宿舍费用",   type: "dorm",    expr: "月人均<13.5不降；13.5~18降≥10%；≥20降≥15%", requireReason: true },
  { id: "R04", cat: "差旅费",     type: "revenue", expr: "营收比≤千分之4，费用增幅≤营收增幅50%", requireReason: true },
  { id: "R05", cat: "绿化费",     type: "green",   expr: "管养单价3~3.5降≥5%；>3.5降≥10%", requireReason: true },
  { id: "R06", cat: "按实际预算类", type: "actual", expr: "据实预算，须详细说明依据", requireReason: true },
];
```

### 2.2 交互（预算编制页）

- 选科目 → 系统按 `BM.RULES` 对应的规则**自动预填基线金额**（如总办办公费按"较2025实际降5%"算出建议值）。
- 若人工修改金额 → **偏离标红** + 弹出"偏离原因"输入框（必填后才能保存），对应 V2 §5.10 规则治理。
- 规则卡在编制页侧边常驻展示，标注"来源：客户预算逻辑指导意见"。

```js
BM.applyRule(cat, lastYearActual) {
  const r = BM.RULES.find(x => x.cat === cat);
  if (!r) return null;
  if (r.type === "down5") return lastYearActual * 0.95;
  // ... 其他规则
}
BM.isDeviated(input, baseline) { return Math.abs(input - baseline) / baseline > 0.01; }
```

## 3. 横向对标视角（P1）

- 预算总览新增 **"对标"视角**（boss/finance 可见）：选定科目，按同类公司/生产单元排列各家预算，自动计算均值/集团线，**标红偏离超过阈值**的单位。
- 数据基础：`BM.COMPANIES` 多家同科目预算（mock，脱敏）。
- 对应客户文件2 汇总表"各子公司横向排列"的逻辑，但系统自动标异而非靠人眼。

---

## 4. 预算碰撞/争议原型（P1）

- 新增 **"碰撞"视图**：对选定科目/公司，展示 `公司申报值` vs `集团建议值`（建议值 = 规则基线 `BM.applyRule`）。
- 展示：差异金额、差异比例、历史执行、可压降空间。
- 对重大差异生成 **"争议项"**，每项支持：提出 → 业务方说明 → 补充证据（文本）→ 状态（待协商/已共识）。
- 对应 V2 §5.2；同时验证 V1"预算碰撞与协商"假设（客户当前疑似弱协商，本原型展示系统化协商价值）。

```js
BM.collisionItems = [
  { cat: "总办办公费", company: "2010", apply: 1140000, suggest: 1200000,
    diff: -60000, status: "待协商", note: "", evidence: "" },
];
```

## 5. 数据结构总览（v0.6 数据扩展）

| 对象 | v0.5 | v0.6 |
|---|---|---|
| 组织 | `BM.ORGS` 2 中心 + `BM.DEPTS` 6 部门 | `BM.COMPANIES` / `BM.BUSINESS_UNITS` / `BM.LEVEL1_DEPTS` / `BM.ORG_TREE` 四级 |
| 科目 | `BM.CATEGORIES` 扁平 | `BM.CATEGORIES` 增 `accountCode`（会计科目编码）、`ownerDept`（归口部门） |
| 规则 | `BM.DEFAULT_RULES`（4 财务规则） | 保留 + 新增 `BM.RULES`（客户编制/压降规则） |
| 碰撞 | 无 | `BM.collisionItems` |
| 对标 | 无 | 复用 `BM.COMPANIES` 多公司同科目 |

`BM.parseBudgetIntent`（v0.5 自由语言归类）保留；`state.rules`、`BM.isPurchaseBlocked`（v0.5 超预算拦截）保留。
