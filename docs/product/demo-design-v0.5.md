## v0.5 核心变化

| # | 变更 | 解决的问题 |
|---|---|---|
| 1 | **二级组织架构** | 部门挂一级中心（行政中心/业务中心），支持多级递归 |
| 2 | **物料清单 BM.MATERIALS**（12 种） | 物料视角的数据基础，每种物料挂科目+项目 |
| 3 | **预算总览多视角**（按角色） | 总经理 4 视角 / 财务 4 视角 / 经理 4 视角 / 员工 2 视角 |

| 6 | **规则影响行为** | 规则立即生效：不允许超预算 → 采购被拦截并提示走追加流程 |

## 1. 多视角预算总览

```text
预算总览（顶菜单入口）
├─ 科目视角    (boss/finance/manager)
├─ 项目视角    (全部 4 角色)
├─ 物料视角    (全部 4 角色)
└─ 人员视角    (boss/finance/manager)
```

| 角色 | 可见 Tab |
|---|---|
| 总经理 | 科目 / 项目 / 物料 / 人员 |
| 财务经理 | 科目 / 项目 / 物料 / 人员 |
| 部门经理 | 科目 / 项目 / 物料 / 人员（本部门范围） |
| 员工 | 项目 | 物料（仅我负责的项目） |

## 2. 自上而下编制新流程

```text
总经理（自由语言）              LLM 归类（规则模拟）              可视化编辑 → 批准
"车辆维修 120 万"           →  cat 车辆维修 120 万     
"显示器项目 7.8 万"         →  material 显示器  7.8 万（映射到项目 P002）
"办公用品 60 万"            →  project 季度办公用品集采 60 万
"IT 设备 80 万"             →  cat IT 设备 80 万
```

- 关键词匹配：物料名 → 项目名 → 科目名（优先级）
- 归类结果→金额可编辑→点击"应用到预算明细"→写入 plan.rows
- 解析函数 `BM.parseBudgetIntent(text)`：支持多句（顿号/逗号/换行分隔）

## 3. 财务规则设置页

| 规则 | 选项 | 含义 |
|---|---|---|
| **编制方式** | 自上而下 / 自下而上 | 决定预算形成方式 |
| **执行追踪** | 实际报销为准 / 申请单预跟踪 | 报销 vs 请款 |
| **期末余量** | 收回 / 挂起 / 结转 | 月/季末未花完预算处理 |
| **超预算** | 允许（走审批接口）/ 不允许（拦截+追加流程） | 风险控制严格度 |

**当前生效规则**在页内以 Badge 形式展示。

## 4. 规则影响行为（v0.5 实现）

```js
BM.isPurchaseBlocked(remain, amount) {
  if (remain >= amount) return false;
  return state.rules.allowOverBudget === false;
}
```

demo 中体现：员工点"发起采购申请"时若超预算，规则不允许 → 提示"⛔ 财务规则不允许超预算，已拦截" → 自动跳转调整中心。
