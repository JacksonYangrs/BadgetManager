# AI 行政预算智能管理平台 · Demo 设计方案 v0.4

> **v0.4 重大重构**：架构调整 + 角色职责差异化 v2
>
> v0.4 在 v0.3 基础上做了 6 项调整：
> 1. 布局重构：**AI Copilot 固定左侧常驻 + 工作台菜单顶部横排 + 右侧内容区**（去掉主 Tab 切换）
> 2. **预算总览 = 同一预算双视图**（科目物料视角 / 项目视角，Tab 切换），采购项目并入预算总览
> 3. **员工审批中心预置数据**，避免空态
> 4. **预算编制按部门**：经理只看到本部门，总经理/财务可下拉切换单部门
> 5. **AI Copilot 按角色差异化**：欢迎语 / 推荐问题 / 风险卡均按角色生成
> 6. 菜单简化：去掉"采购项目"独立菜单（合并到预算总览双视图）

---

## 1. 新布局（核心变化）

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶栏: 品牌 | [工作台菜单横排: 首页 | 预算总览 | 明细 | ...] | 角色 | 重置 │
├──────────────────┬──────────────────────────────────────────┤
│ AI Budget        │  工作台内容区                            │
│ Copilot          │                                          │
│ (固定左侧常驻)    │  (顶部菜单切换)                          │
│                  │                                          │
│ 欢迎语           │                                          │
│ 推荐问题(角色)   │                                          │
│ 风险卡(角色)     │                                          │
│                  │                                          │
│ ───────────       │                                          │
│ 对话流           │                                          │
│ 输入框           │                                          │
└──────────────────┴──────────────────────────────────────────┘
```

**核心变化**：AI Copilot **不再被主 Tab 切换隐藏**，始终在左；右侧内容按角色菜单切换。

## 2. 预算总览双视图

```text
预算总览
├─ Tab: 科目·物料视角  (原 dashboard 内容)
└─ Tab: 项目视角       (原 projects 内容)
```

**角色权限矩阵**（v0.4 修订）：

| 角色 | 顶部菜单 |
|---|---|
| 总经理 | 工作台首页 / 预算总览 / 明细 / 审批中心 / 决策中心 / 预算编制 / 预算追踪 / 预算调整 / 决算 |
| 财务经理 | 同总经理（9 项） |
| 部门经理 | 工作台首页 / 预算总览 / 明细 / 审批中心 / 预算编制 / 预算追踪 |
| 员工 | 工作台首页 / 审批中心 |

## 3. Copilot 按角色差异化

| 角色 | 欢迎语 | 推荐问题示例 | 风险卡内容 |
|---|---|---|---|
| 总经理 | 全局预算的风险、趋势与决策 | "哪个部门今年最容易超预算？" "今年行政费用整体情况怎么样？" "IT 设备超支怎么解决？" | IT 设备超 35%、车辆维修超 18%、培训费节余 |
| 财务经理 | 预算口径、执行总控与调整 | "哪些项目需要调整预算？" "今年决算大概是什么情况？" "有没有成本优化建议？" | 待审批单、编制进度、培训费调剂 |
| 部门经理 | 本部门预算执行与项目偏差 | "本部门哪个项目风险最高？" "本部门预算还剩多少？" | 车辆维修 +9%、办公用品合理增长 |
| 员工 | 项目预算与申请进度 | "我负责的项目还剩多少预算？" "我的采购申请到哪一步了？" | 显示器项目余额、办公电脑待启动 |

## 4. 预算编制按部门

| 角色 | 自下而上 | 自上而下 |
|---|---|---|
| 部门经理 | 只看到本部门填报 | 不适用 |
| 总经理 | 默认全部部门，可下拉切换单部门 | 按部门行展示（分解模式） |
| 财务经理 | 同总经理，可下拉切换 | 同总经理 |

## 5. 审批中心修复

员工角色预置 2 张自己发起的单据：
- APR005 显示器采购申请 7.8 万
- APR006 办公椅报销 1800 元

加上运行时从"采购/报销"发起的，所有角色进审批中心都不空。

## 6. 角色说明条（沿用 v0.3）

每个页面顶部一行"此页面与您的关系 + 您的行动"，4 角色文案不同。
