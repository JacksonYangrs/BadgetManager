## v0.3 核心变化

| # | 变更 | 解决什么问题 |
|---|---|---|
| 1 | **预算颗粒度落到采购项目级** | 预算管理"黑箱"——员工不知道"我与预算的关系是什么"。项目+负责人让员工直接看到"我负责的项目预算约束" |
| 2 | **员工角色重构** | 员工不该看全局明细——改为「我的项目」，只看自己负责的采购项目 + 每项目预算约束 |
| 3 | **财务管理员 → 财务经理** | 体现"总控价值"——新增「预算调整中心」：项目级调剂/追加/调减 |
| 4 | **每个页面加角色说明条** | 同一页面因角色不同，职责相关性显性化 |
| 5 | **采购页面加 Copilot 项目问答** | "我负责的项目还剩多少预算？" |

## 1. 项目颗粒度模型

### 预算链路 v0.3

```text
编制（自上而下 / 自下而上）
        ↓
部门 × 科目
        ↓
具体到每一个采购项目（预算最小颗粒度）
        ↓
项目负责人
        ↓
登录后直接看到"我的项目预算约束"
```

### 项目实体属性

| 字段 | 说明 |
|---|---|
| id | 项目编号（如 P001） |
| name | 项目名称 |
| deptId / catId | 所属部门 / 科目 |
| budget | 分配预算额度 |
| used / frozen | 已用 / 冻结金额 |
| owner | 负责人姓名 |
| ownerRole | 负责人角色 |
| status | 编制中 / 执行中 / 已结项 |
| desc | 项目说明 |

## 2. 角色权限矩阵（v0.3 修订）

| 角色 | 可见视图 | 数据范围 |
|---|---|---|
| **总经理** | 工作台首页 / **采购项目** / 预算总览 / 明细 / 审批中心 / 决策中心 / 预算编制 / 预算追踪 / **预算调整** / 决算 | 全局 |
| **财务经理**（改名） | 同总经理（除审批中心权限相同） | 全局 |
| **部门经理** | 工作台首页 / **采购项目** / 预算总览（本部门） / 明细 / 审批中心 / 预算编制 / 预算追踪 | 本部门 |
| **员工** | 工作台首页 / **采购项目** / 审批中心 | **仅我负责的项目** |

## 3. 员工角色重构

| 之前 | v0.3 |
|---|---|
| 能看全局明细（不合理） | 不看明细 |
| 看到所有审批单（看不全） | 「我的项目」—— 我负责的项目卡片 |
| — | 项目卡片显示：额度 / 已用 / 冻结 / 剩余 / 执行率 / 状态 / 负责人 |
| — | 每卡「发起采购申请」按钮，按钮调项目级 AI 初审 |

员工与预算的关系 = **"我是项目负责人，我管项目预算"**，不再抽象。

## 4. 财务经理预算调整中心

| 类型 | 说明 |
|---|---|
| 调剂 transfer | 项目间转移预算额度 |
| 追加 add | 给项目追加额度 |
| 调减 cut | 收回项目未用额度 |

流程：财务经理发起 → AI 初审（大额 >20 万自动标人工复核）→ 总经理终批 → 批准后项目预算自动更新。

## 5. 角色说明条（每个页面顶部）

```text
▍ [此页面跟您角色的关系 + 您的行动入口]
```

**示例（同一预算总览页面对四角色）：**

| 角色 | 说明条文案 |
|---|---|
| 总经理 | 全局预算执行与风险，您是最终决策人。 |
| 财务经理 | 预算口径与执行总控，超支科目需您审核调整。 |
| 部门经理 | 仅显示本部门口径，偏差科目需您说明原因。 |
| 员工 | 全局预算仅供了解，您的工作重点是负责的项目。 |

## 6. Copilot 项目问答

| 用户问 | 返回 |
|---|---|
| "我负责的项目还剩多少预算？" | 列出所有可见项目（按角色范围）的额度/已用/剩余/执行率 |

## 8. 验收标准（v0.3 增量）

- 员工登录后：导航仅 3 项，无明细、无总览；首页有 2 张项目卡片 + 「发起采购申请」按钮
- 财务经理登录后：可见「预算调整中心」，可发起/审批调整
- 每个页面顶部有角色说明条，4 角色文案不同
- 总经理项目总览：10 张项目卡片，全局 KPI
- 部门经理项目：3 张（行政部 3 个项目）
- Copilot 项目问答按角色范围返回
- 调整申请提交后：总经理可见审批按钮；批准后项目额度自动更新（已 Node 验证）
