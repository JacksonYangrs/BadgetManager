## 1. 双入口架构

```text
┌─────────────────────────────────────────────────┐
│  工作台（传统路径）     |     AI Copilot（智能）  │
│                                                  │
│  - 角色首页（待办+快捷）   - 对话框（推荐问题）    │
│  - 预算总览/明细/审批     - 四类卡片（预测/分析）  │
│  - 决策/编制/追踪/决算     - 证据链               │
│                                                  │
│  数据范围：按角色隔离      范围：当前角色可见数据    │
└─────────────────────────────────────────────────┘
```

## 2. 角色与权限矩阵

| 角色 | 可见视图 | 数据范围 | 典型任务 |
|---|---|---|---|
| **总经理** | 工作台首页 / 预算总览 / 明细 / 审批 / 决策 / 编制 / 追踪 / 决算 | 全局 | 全局决策 · 终审 · 决算 |
| **财务管理员** | 同总经理 | 全局 | 预算汇总 · 调整 · 决算 |
| **部门经理** | 工作台首页 / 预算总览（本部门） / 明细 / 审批 / 编制 / 追踪 | 本部门 | 编制填报 · 部门审批 · 偏差追踪 |
| **员工** | 工作台首页 / 明细 / 审批 | 本人发起 | 发起采购/报销 · 进度查看 |

权限实现：`BM.roleViews(role)` 返回可见视图 key 列表；导航层过滤；渲染层用 `BM.scopedDocs()` / `BM.scopedApprovals()` 控制数据范围。

## 3. 角色工作台首页（统一框架）

每个角色登录后看到三段式首页：

- **欢迎条**：角色名 + 角色视角说明
- **今日待办**：按角色生成（boss: 待审批/风险/编制审批；manager: 本部门编制/偏差；staff: 我的采购/报销）
- **常用功能**：角色可访问的核心功能卡片网格
- **AI 正在为您关注**：AI 主动推送的洞察列表

## 4. 预算编制（双模式）

### 模式选择（页内 Tab 切换）

| 模式 | 流程 | 适用角色 |
|---|---|---|
| **自上而下分解** | 总经理定年度总额 → AI 按历史占比分配到部门 → 编辑 → 提交 | 总经理 / 财务 |
| **自下而上填报** | 部门经理填报本部门各科目预算 → 财务汇总 → 总经理批 | 经理填报 / 财务汇总 / 总经理批 |

### AI 编制助手

- 按 1-9 月历史执行年化 + 8% 缓冲生成建议额度（按部门 × 科目）
- 用户可一键采用建议，也可手动修改
- 提交前 AI 提示："本部门整体超出年度总额 X%"

### 流程状态机

```text
编制中(draft) → 部门填报(submitted) → 财务汇总(finance_approved) → 总经理审批(approved)
                    ↓                                                ↑
                退回修改(rejected) ←─────────────────────────── 驳回
```

### 两种模式数据关系

- 自上而下模式：在 `plan.rows[deptId]` 记录每部门总额
- 自下而上模式：在 `plan.rows["{deptId}:{catId}"]` 记录每部门每科目金额
- 两种模式可共存，但状态机驱动同一份计划

## 5. 预算追踪

| 元素 | 内容 |
|---|---|
| 月度执行表 | 12 月（1-9 实际 + 10-12 预测）· 8 科目 |

| 偏差归因 | 列出超支科目 + 标注"需 9 月内决策" |

## 7. 现有页面（v0.1 → v0.2 改造）

| 页面 | 改动 |
|---|---|
| 预算总览 | 加 scope 感知：boss/finance 看全局；manager 看本部门口径；staff 默认 IT 部 |

| 审批中心 | 数据源改为 `BM.scopedApprovals()`；staff 无审批按钮 |

## 8. 视觉与交互补充

- 顶栏：增加主 Tab 切换（金色高亮"工作台"或"AI Copilot"）
- 工作台：左侧子导航（垂直，190px 宽）+ 右侧内容
- 登录页：4 张角色卡网格 + 部门经理专属"选部门"步骤
- 顶栏角色显示：`角色 · 姓名（部门）`
- URL deep-link：`?as=boss#plan` 等

## 9. 验收标准（v0.2 增量）

- 4 角色可登录，子导航与可见页面按权限矩阵严格过滤
- 数据范围：manager 只看本部门，staff 只看自己发起的单据
- 编制流程：经理提交 → 财务汇总 → 总经理批 完整跑通
- 追踪页：10-12 月预测列正确显示，无 NaN
- 决算页：超支/节余的颜色与文案严格正确（varAmt > 0 = 超支）
- 工作台首页：每角色看到不同的待办与功能入口
- 双 Tab 切换：工作台与 Copilot 视图独立渲染
