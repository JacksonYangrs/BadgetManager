发现清单

P1 brand-expression

证据：logo sanan.png 主色 #003CB4；site CSS --c-primary #1E2A4A，brand-mark 为通用柱状图 SVG，无 Sanan 图形/文字标识

业务影响：访问者无法将界面与 Sanan / 三安制造品牌建立关联，信任感与品牌一致性受损

修复：以 logo 蓝 (#003CB4) 替换当前深蓝主色；在登录页与顶栏置入 Sanan 图形标识+"三安制造"文字标；删除/弱化金色，仅作为状态点缀

P1 content-llm-visibility / technical-seo

证据：capture.json: loginMeta/appMeta h1s=[], h2s=[], h3s=[]；页面内容通过 JS 渲染

业务影响：搜索引擎与 AI 摘要几乎无法识别页面主题、角色与价值主张，自然流量与 AI 推荐为零

修复：为登录页/落地页补充语义化 h1/h2；增加一段静态价值主张文本；对关键视图做预渲染或 SSR

P1 technical-seo / content-llm-visibility

证据：curl 探测：/robots.txt、/sitemap.xml、/llms.txt 均返回 404；HTML 无 canonical、无 JSON-LD、无 OG

业务影响：站点对爬虫不可索引、对 LLM 不可引用，Demo 无法被外部发现

修复：添加 robots.txt 允许抓取、sitemap.xml、canonical 自引用、Organization/Product JSON-LD、llms.txt；补充 OG 标签

P2 conversion-focus

证据：appMeta.navLabels: 工作台首页/预算编制/预算跟踪/预算规划/预算工作人员/基础数据；copilot suggestions: "我负责的项目还剩多少预算？" 等；CTA 标签体系不一致

业务影响：用户在不同入口看到不同词汇，增加认知负荷，降低 AI Copilot 采纳率

修复：统一导航与 Copilot 快捷问题的术语；将问句改为动作按钮文案（如"查看剩余预算"）

P2 visual-hierarchy-craft

证据：app-mobile.png 顶栏标题截断、导航未做响应式折叠

业务影响：移动端首屏信息丢失，关键导航被隐藏或拥挤

修复：移动端将长标题缩写为"三安 AI 费控"，导航收进抽屉菜单；为信息卡片增加视觉分组与图标色区分

P2 accessibility

证据：CSS --c-text-3: #9098AB 在 #FFFFFF 上对比度 2.89:1（< 4.5:1），用于时间戳/提示小字

业务影响：低视力用户难以阅读辅助说明文字

修复：将次要文字色加深至 #6B7280 或更大字号，确保小字对比度 ≥ 4.5:1

P2 technical-seo

证据：HEAD 探测无 og:title/og:image；无 canonical

业务影响：社交分享与搜索引擎结果缺少吸引力片段，权重分散

修复：补全 og:title、og:description、og:image、twitter:card；添加

P3 brand-expression

证据：theme-color meta 为 #1e2a4a，与 logo 蓝不一致

业务影响：浏览器/ PWA 标题栏颜色与品牌主色脱节

修复：theme-color 改为 #003CB4，与 Sanan 品牌一致

基于 Logo 的 Redesign 方向

方向 A：Faithful + Fixes（品牌校准）

定位：保留现有功能布局与信息架构，将视觉系统全面迁移到 Sanan 品牌色。

  • 主色：#003CB4（logo 蓝）替代 #1E2A4A；深色背景仅在需要时使用 #002A7E
  • 登录页与顶栏使用 Sanan 图形标 + "三安制造" 文字标
  • 金色仅保留为成功/高亮状态色，降低视觉噪音
  • 补充 h1/h2 语义、静态价值主张、robots/sitemap/JSON-LD/llms.txt

解决：P1 品牌断裂 · P1 无语义标题 · P1 SEO/LLM 不可见 · P3 theme-color

方向 B：Amplify "Precision"（精准感放大）

定位：将 logo 中 C 形弧线提炼为"精准仪表盘"视觉母题，强化 AI 费控的可靠感。

  • 顶栏/仪表盘使用 C 弧线进度环与动态数据卡片
  • 保留蓝白基调，关键数字使用大字号 tabular-nums
  • Copilot 面板使用品牌弧线装饰，提示问题分组为"查预算 / 追流程 / 审风险"

解决：P2 CTA 词汇碎片化 · P2 移动端层级混乱 · P1 品牌无记忆点

方向 C：Cinematic Motion（克制动效身份）

定位：以 C 弧线扫过作为页面切换与加载的签名动效，保持 B2B 产品稳重感。

  • 页面进入：内容从右向左淡入，时长 240ms，ease-out
  • 加载状态：logo C 弧线 120° 旋转，脉冲 1.2s
  • 卡片 hover：微妙上浮 + 阴影加深，避免过度炫技
  • 注册：calm-measured（冷静、可度量）

解决：P2 视觉层级弱 · P1 品牌无差异化
